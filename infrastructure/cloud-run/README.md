# Cloud Run reference services

These examples define the Phase 12 runtime contract for Phase 13 Terraform. They are not independently managed
production manifests. Replace uppercase placeholders, select environment-specific audiences, and pin image and
secret versions. IAM bindings, push subscriptions, database migrations, and network prerequisites are separate.

See [the runbook](../../docs/cloud-run.md) for build commands, budgets, identity grants, delivery settings, validation,
and rollout/rollback requirements.
